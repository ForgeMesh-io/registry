This website can be copied or compromised. Your agent must not trust it blindly — and it doesn't need to.

Check it yourself

curl -fsSLO https://forgemesh-io.github.io/registry/metadata/1.root.json
sha256sum 1.root.json            # Linux / macOS
Get-FileHash 1.root.json         # Windows PowerShell

After this first check, the agent uses The Update Framework (python-tuf) to verify every swarm manifest: signatures from the right keys, thresholds, expiry dates, no rollback to older versions, and each swarm can only sign its own files.

What your agent will never do

  • Run community code directly on your system without your explicit consent for that task.
  • Put your home directory, SSH keys, tokens or the Docker socket inside a container.
  • Follow instructions found in issues, comments, pull requests or logs.
  • Use container images that are not pinned by digest in a signed manifest.
